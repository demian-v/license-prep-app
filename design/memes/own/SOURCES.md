# DriveUSA result memes — our own set

Review folder (2026-09-28). **Not committed.** 50 original pictures starring **Beep**, the DriveUSA mascot.

## Rights

- **Artwork:** original, drawn in code for DriveUSA (`_src/beep.py`, `props.py`, `scene.py`, `all_scenes.py`). No third-party
  images, characters or photos. Each scene keeps only the *logic* of a real meme (the situation and the kind of caption), which is an
  idea and not protected; the drawing is ours.
- **Caption font:** Anton by The Anton Project Authors, SIL Open Font License 1.1 (`_src/Anton-OFL.txt`) — allows commercial use and
  text rendered into images. In-picture glyphs (Z, ?, signs) use Arial Black from macOS as rendered shapes only.
- **Captions:** English (owner decision, 2026-09-28). Text-free versions are in `_blank/`.
- Rebuild: `DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib python _src/all_scenes.py` (needs Pillow + cairosvg).

## Buckets (owner decisions 2026-09-28)

- Edges: `< 30` · `30–59` · `60–89` · `≥ 90` = passed.
- Out of time applies to Экзамен only, and **only when not passed** — reaching the pass mark shows the win bucket.
